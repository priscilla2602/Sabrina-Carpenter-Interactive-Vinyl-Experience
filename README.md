# 🎀 Sabrina Carpenter | Interactive Vinyl Experience

Um projeto web completo, interativo e com design editorial dedicado à discografia, trajetória e estética da artista pop **Sabrina Carpenter**. 

Este site foi desenvolvido com foco em UI/UX, utilizando uma estética de "revista de alta moda" combinada com elementos nostálgicos, destacando-se por um **player de vinil totalmente interativo** criado do zero com JavaScript e animações CSS.

---

## ✨ Funcionalidade

* **🎧 Player de Vinil Interativo:** Ao clicar em um álbum, um disco de vinil desliza para fora da capa e começa a girar com animações CSS contínuas enquanto a música toca.
* **📂 Navegação Dinâmica:** Sistema de abas em JavaScript puro que permite transitar entre seções (Início, Biografia, Discografia e Galeria) sem recarregar a página.
* **🎵 Discografia Completa:** 7 álbuns mapeados com suas respectivas tracklists originais.
* **📱 Design 100% Responsivo:** O layout se adapta perfeitamente a dispositivos móveis, tablets e telas maiores.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando apenas as tecnologias base da web, sem frameworks, para garantir máxima performance e demonstrar domínio de front-end nativo:

* **HTML5:** Semântica e estruturação do conteúdo.
* **CSS3:** Estilização, variáveis globais (Custom Properties), Grid Layout, Flexbox e animações avançadas (`@keyframes`).
* **JavaScript (Vanilla):** Lógica de controle do áudio (`HTMLAudioElement`), manipulação do DOM e controle de estado das abas e faixas musicais.
* **FontAwesome:** Ícones vetoriais.
* **Google Fonts:** Tipografia dinâmica.
